Install

  1. Download the DMG and drag the app into Applications.
  2. Paste this once. macOS blocks unsigned apps until you do.
xattr -dr com.apple.quarantine "/Applications/Local file search.app"

Open it and add a folder. The first search downloads the 4.43 GB model. This happens once.
